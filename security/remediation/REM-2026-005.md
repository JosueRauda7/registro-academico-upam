# REM-2026-005 — Comprobantes privados y logos públicos

- Fecha/responsable: 2026-10-28, Codex. Hallazgo: [FINDING-2026-005](../findings/FINDING-2026-005.md). Estado final: CLOSED.
- Causa: logos/comprobantes compartían directorio estático y caché pública.
- Solución: únicamente uploads/logos es estático; carga de logo exige administrator. Comprobantes nuevos van a uploads/receipts y su descarga autenticada valida propietario student o administrator/collector, con private,no-store. Se conservan referencias antiguas a archivos raíz y se descargan mediante la ruta privada; Nginx bloquea los antiguos enlaces públicos. Frontend usa Axios autenticado y descarga Blob sin tokens en URLs. Script de migración copia el logo configurado solo si no está referenciado como comprobante.
- Archivos: main.ts, módulo/controller/service uploads, payment.repository.ts, payments.service.ts, frontend/nginx.conf, API uploads/payments, SettingsPage.tsx, ColecturiaPage.tsx y scripts/migrate-local-logo.cjs.
- Re-test: cargas sharp reales en Docker; lectura anónima/ajena denegada, dueño y roles financieros permitidos; rutas antiguas bloqueadas; private,no-store verificado; logos públicos accesibles. Logo anterior migrado y original conservado.
- Resultado: lectura financiera pública corregida. [Evidencia](../evidence/2026-10-28-remediation-tests.md).
- Límite: copias previamente descargadas o cacheadas por terceros no pueden revocarse. Administrador/colector pueden leer archivos financieros aún no asociados; definir retención/limpieza futura. Cierre: 2026-10-28; árbol local sobre f9be37d.
